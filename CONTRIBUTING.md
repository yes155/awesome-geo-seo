# Contributing to Awesome GEO SEO

Thanks for your interest in contributing!

## How to contribute

- Add high-quality GEO or Semantic SEO resources.
- Avoid duplicate links.
- Include a short description (1–2 sentences).
- Place the resource in the correct category.
- Keep formatting consistent with the rest of the repository.

## Pull Requests

1. Fork the repository.
2. Create a new branch.
3. Make your changes.
4. Submit a pull request.

Thank you for helping improve Awesome GEO SEO!
